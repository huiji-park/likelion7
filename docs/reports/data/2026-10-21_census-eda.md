# 인구총조사 통계표 메타데이터·수치 표본 EDA

- 작성: data-engineer · 날짜: 2026-10-21
- 종류: EDA
- 관련 단계: 실전2 (통계표 안내 챗봇) 준비, 실전1 수치 조회 사전 점검

## 1. 목적
KOSIS "인구총조사"(작성기관 국가데이터처, orgId=101) 통계표의 (1) 목록과 건수를 멘토링 자료의 1,876건과 대조하고, (2) 통계표 메타(수록기간·주기, 분류, 항목, 단위)를 전수 수집해 구조를 파악하며, (3) 수치 응답의 표기 특성을 표본으로 확인한다. 지역통계(시도·시군구별 지역통계 메뉴)는 범위 밖이며 수집하지 않았다(주제별 뷰 `V` 하위는 탐색하지 않음).

## 2. 데이터·대상
- 조회 일시: 2026-10-21 (통계표 최종 갱신일 `SEND_DE` 범위 2007-05-17 ~ 2026-08-04).
- 목록: KOSIS OpenAPI `statisticsList.do` (method=getList). 출발점은 두 곳.
  - `vwCd=MT_ZTITLE`(국내통계 주제별), `parentListId=A_4` (인구 > 인구총조사)
  - `vwCd=MT_OTITLE`(국내통계 기관별), `parentListId=MT_CTITLE_A` (국가데이터처 > 인구총조사)
  - 두 출발점은 상위 목록(`MT_ZTITLE`/`A`, `MT_OTITLE`/`101`)을 조회해 이름으로 찾은 값이다.
- 메타: `statisticsData.do?method=getMeta` 의 `type=TBL`(표명), `PRD`(수록기간·주기), `ITM`(분류값+항목+단위)을 표마다 호출. 개발가이드(https://kosis.kr/openapi/)는 SSO 리다이렉트로 본문을 못 읽었고, 하위 가이드 페이지는 일부만 확인됐다(통계설명 API, 통계자료 파라미터). 따라서 `getMeta`의 type 값은 가이드가 아니라 실제 호출로 확인했다(아래 4.9).
- 수치: `Param/statisticsParameterData.do` (method=getList), 표본 36개 표.

## 3. 수행 내용
작업 폴더는 worktree `../likelion7-wt/data`, 브랜치 `data/census-eda`. Python 3.12.14 (uv venv). 실행 순서:

```bash
uv venv --python 3.12 && uv pip install -r requirements.txt
# 키: 환경변수 KOSIS_API_KEY 또는 KOSIS_ENV_PATH(.env 경로). 없으면 코드에 적힌 기본 .env 경로를 읽는다.
.venv/Scripts/python.exe -m src.meta.collect_list      # 1. 통계표 목록 (data/raw/list_*.jsonl)
.venv/Scripts/python.exe -m src.meta.collect_meta      # 2. 메타 (data/raw/meta_compact.jsonl, 재개 가능)
.venv/Scripts/python.exe -m src.meta.clean             # 4. 정제본 data/processed/meta_tables.jsonl
.venv/Scripts/python.exe -m src.meta.profile           # 5. EDA 그림·통계 (data/processed/profile_stats.json)
.venv/Scripts/python.exe -m src.meta.collect_sample --n 36   # 3. 수치 표본 (data/raw/sample/)
.venv/Scripts/python.exe -m src.meta.profile_sample    # 표본 프로파일 (data/processed/sample_stats.json)
```

- API 클라이언트 `src/kosis/client.py`: 캐시(`data/cache/`, 키는 캐시 키·파일명에 미포함), 호출 간 0.4초 지연, 재시도, KOSIS err 40(분당 200건 초과) 시 62초 대기 후 재시도, 응답 바이트를 UTF-8 우선 디코딩, 키 마스킹(`mask`).
- 수집·프로파일링 스크립트 `src/meta/`: `collect_list.py`, `collect_meta.py`, `clean.py`, `profile.py`, `collect_sample.py`, `profile_sample.py`.
- 소요 시간: 목록 재귀 탐색은 분당 200건 제한에 한 번 걸려 재시도했다(정확한 시간은 미측정, 분 단위). 메타 1,901표 × 3호출은 2,296초(약 38분). 수치 표본 36표는 수 분 내.

### 4.7 수치 표본 (36표 요청, 35표 성공)
**선정 기준**(결정적, 난수 없음; `src/meta/collect_sample.py`의 `select_sample`): 정제본에서 (a) 주기 3종, 분류 수 1~5, 부문 4종 각각의 추정 셀 수가 중간인 소형 표(추정 3만 셀 이하), (b) 셀 수 20만 초과 대형 표 3건(상·중·하; 40,000셀 제한 폴백 경로 검증용), (c) 나머지는 하위분류(조사 연도) 폴더를 순회하며 채움. 36표 중 5년 주기 28, 년 4, 부정기 4(5년 주기 비중이 큰 것은 모집단 구성 때문). 각 표 최근 2개 시점(`newEstPrdCnt=2`), 항목·분류값 ALL.
- 성공 35표, 200,868행. 실패 1건: `DT_1BC0503` — err 31 "40,000셀을 초과한 결과값은 요청하실 수 없습니다"(ALL 요청 및 objL1 상위 3개/1개 폴백까지 실패 시 중단). 4표(`DT_1GAOO08`, `DT_1IN0001_39`, `DT_1IN0508`, `DT_1TS1003`)는 ALL이 31 오류라 objL1을 상위 코드 3개로 제한해 받았다(부분 데이터).
- **결측·특수기호**: 응답 `DT`는 문자열. 숫자 형식이 아닌 값은 표본 전체에서 **`-` 한 종류뿐**(12,191행, 6.07%, 9개 표). `…`, `x`, 빈 문자열은 표본에서 관측되지 않음. `-`와 `0`은 같은 표에 공존한다(예: `DT_1GA7505`에 `-` 38행, `0` 4행) — 구분해야 함. `-`의 의미(해당 없음/비공개)는 응답에서 확인되지 않음(`smblChk=Y`를 줘도 `DT_1BD9501`의 `DT` 값은 바뀌지 않았다). 의미는 미확인.
- 0 값: 17개 표에 존재(최대 `DT_1GA9005` 3,011행). 음수 0건. 소수점 값은 3개 표(`DT_1B08024` 32행, `DT_1IN0001_39` 209행, `DT_1IN3503` 205행) — 인구밀도, 성비(여자백명당남자수) 등 비율 항목.
- 단위: 응답 `UNIT_NM` 종류 가구·명·호·개·여자백명당남자수·명/㎢, 그리고 **비어 있는 행 18,329건(9.1%)**. 한 표에서 가구와 명이 섞이는 표가 있다(`DT_1GA7001`, `DT_1GA8509`, `DT_1GA9005`).
- 시점: `PRD_DE`는 전부 `YYYY` 4자리. `PRD_SE` 응답 코드는 5년 주기 표를 `prdSe=F`로 요청했을 때 `A`, 부정기는 `IR`로 돌아온다. 5년 주기는 `prdSe=Y`로는 err 30(데이터 없음)이 난다(소형 표 `DT_1GA5502`로 확인, `Y`/`IR`/`D` 모두 err 30, `F`만 성공).
- 값 범위: 최대값은 4.7천만(`DT_1PK1513`) 단위이고 표별 최소·최대는 `data/processed/sample_stats.json`. `LST_CHN_DE`(최종변경일)는 65,120행(32.4%)이 빈 값. 복합키(C1..C8, ITM_ID, PRD_DE) 중복 0건.
- 재조회 일치: `DT_1BD9501`을 캐시 없이 다시 호출해 8,667행이 완전히 동일함을 확인(1건). 전 표 재조회 검증은 하지 않았다.
- 그림 `figures/10_sample_nonnumeric.png`(표별 비숫자·0 비율). 코드 `src/meta/profile_sample.py`.

## 5. 한계·미확인 사항
- 1,876건의 멘토링 자료 집계 기준은 미확인(STAT_ID=1962001 건수와 일치하는 것만 확인).
- 세종시 22건이 "세종시 특별센서스"와 같은 것인지, 이번 인구총조사 범위에 넣을지는 미확인.
- 메타의 `PRD`는 표별 시작·끝만 주므로 중간 시점의 결측 여부는 모른다(`NCD` 타입은 시점별 갱신일을 주지만 이번에는 수집하지 않았다).
- 분류 종류는 분류명 키워드 규칙이라 "기타" 209표 등 오분류가 있을 수 있다. 규칙은 `profile.py`.
- 셀 수 추정은 상한이며 실제 응답 행 수와 다르다(예: `DT_1GAOO08` 추정 203,472, 폴백 응답 1,944행).
- 수치 표본은 36표(1.9%)이며 최근 2개 시점만이다. 대형 표, 시계열 긴 표는 대표성이 낮다. `DT_1BC0503`은 응답을 못 받았고 4표는 부분 응답이다.
- `-` 기호의 의미, 빈 단위의 원인, 2025년 인구주택총조사 결과 표의 존재 여부는 미확인.
- 주제별 뷰에서만 시작했으므로 인구총조사 표가 다른 주제 폴더에도 있는지는 확인하지 않았다(기관별 뷰와는 대조함).
- 통계표 갱신으로 목록·메타는 시간이 지나며 바뀐다. 이번 값은 2026-10-21 기준.

## 6. 다른 역할에 대한 요청 / 다음 단계
**ai-engineer (검색·질의 매핑)**
- 조사 연도는 표명에 거의 없고 경로에만 있다(`name_group`). 검색 텍스트에 경로 하위분류를 반드시 포함하고, "2020년 기준" 같은 질의를 폴더(표본(20%) 2015/2020, 총조사 연도)로 매핑해야 한다. `search_text`에 경로가 들어 있다.
- 같은 표명이 연도 폴더마다 반복(322묶음, 698표)되므로, 표명만으로 순위를 매기면 구분이 안 된다. 후보 표를 연도·지역 단계(시도/시군구/읍면동)로 구분해 제시해야 한다.
- 표명 끝 지역 단계(` - 시도`/`시군구`)와 `행정구역별(시도)` 같은 분류명으로 지역 단계를 질의와 맞출 수 있다.
- 수치 조회: 5년 주기는 `prdSe=F`, 부정기는 `IR`, 연간은 `Y`. 응답 `PRD_SE`는 `A`로 돌아오므로 요청 코드와 구분해 저장. 표의 40,000셀 제한이 620표(추정)에서 걸릴 수 있으므로 분류값 지정이 필수(전체 `ALL` 금지). 메타의 분류값 코드(`UP_ITM_ID` 계층)를 이용해 시도 단위 코드만 골라 요청한다.
- 단위가 비어 있는 표(62.5%)와 한 표 내 단위 혼재(135표)가 있어 응답문 생성 시 단위를 항목별로 읽어야 한다.

**eval-engineer (골든셋)**
- 정답 표가 여러 개인 질문(연도 쌍, 지역 단계 쌍)을 골든셋에 일부러 넣을 것. 정답을 tbl_id 1개로 두면 안 되는 경우가 많다(4.6).
- 수치 정답은 `-`(값 없음)와 `0`을 구분하는 케이스를 포함할 것. 최신 시점이 2020(표본)과 2025(등록센서스 기반 연간)로 갈리므로 "최신" 질문의 기준 시점을 명시해야 한다.
- `data/processed/meta_tables.jsonl`의 `in_1876`로 1,876 범위만 쓸지, 세종시·시계열 연계 25건을 넣을지 project-lead 결정 필요.

**project-lead**
- 1,876 집계 기준 확인(멘토링 자료)과 `docs/interfaces.md` 스키마 확정 요청.
- 인구총조사 외 13개 조사 수집은 같은 코드로 확장 가능(출발 `parentListId`만 바뀜: 주제별 `A_*` 폴더 목록은 `MT_ZTITLE`/`A` 하위에서 확인됨). 다만 일부 조사는 작성기관이 달라 ORG_ID가 다르다.
